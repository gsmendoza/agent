# Tailor Resume

## Description

- Tailor a copy of the latest resume to a job posting. Use when the user wants to apply to a job and provides a job posting and tailoring instructions.

## Input

- A job posting that the user wants to apply to.

- Instructions from the user on how he'd like the latest resume to be tailored for the job posting.

## Instructions

- Read README.md for the path of the latest resume.

- Create a copy of the latest resume and tailor it to the job posting based on the user's instructions.
  - Save the copy in the job posting directory.
